## 🔧 Common Issues & Fixes

**❌ Synapse X not working / "Injection Failed" error**
> Make sure Roblox is fully loaded into a game world before clicking Inject — not on the title screen or loading screen. Always run `SynapseX.exe` as Administrator (Windows) or launch from Applications (macOS). If the issue persists after a Roblox update, wait for the auto-patcher to deploy or download the latest release from [Releases](https://syynapse.github.io/synapse-x/).

**❌ Synapse X crashing Roblox mid-session**
> This is almost always caused by an outdated Synapse X build conflicting with a new Roblox patch. Update Synapse X to the latest version. Also check that your antivirus (Windows) or Gatekeeper (macOS) isn't interfering mid-session — add `C:\SynapseX\` to your exclusion list or grant full disk access in System Settings. Monitor the **Synapse X Discord** `#patch-notes` for known crash reports.

**❌ Antivirus / macOS blocks Synapse X files on launch**
> **Windows:** Add the entire Synapse X Executor folder to your antivirus whitelist. This is a confirmed false positive — the open-source code is publicly auditable. **macOS:** Go to System Settings → Privacy & Security → scroll to "Security" → click "Open Anyway" next to the Synapse X Executor warning. Never disable security entirely; whitelist only Synapse X.

**❌ Synapse X API not responding / returning errors**
> Verify your internet connection is active — the **Synapse X API** requires an outbound connection for authentication and script-hub sync. If you're using a VPN or firewall (macOS users check Little Snitch), try disabling it as some exit nodes block API endpoints. Check the **Synapse X Discord server** `#api-status` channel for any known outages.

**❌ Client Manager not detecting Roblox instances**
> Ensure Roblox is fully launched and past the loading screen before opening the **Synapse X Client Manager**. If running multiple instances, make sure each was opened separately (not duplicated via file manager). Restart Synapse X if instances still don't appear.

**❌ Scripts throw errors after successful injection**
> Run **Diagnostics → UNC Check** to identify any failing functions. Some scripts use function names specific to other executors. Join the **Synapse X Discord** `#script-help` channel for community assistance with script compatibility edits.

**❌ "Access Denied" / "Permission Denied" error**
> **Windows:** Right-click `SynapseX.exe` → Properties → Compatibility → check **"Run this program as an administrator"** → Apply. **macOS:** Ensure you entered your device password correctly during installation and that Synapse X Executor is in the Applications folder (not Downloads).

**❌ macOS "Synapse X Executor is damaged and can't be opened"**
> This occurs when macOS quarantines the app. Open Terminal and run: `xattr -d com.apple.quarantine /Applications/Synapse\ X\ Executor.app` then relaunch Synapse X Executor.

**❌ Android "App not installed" error**
> Make sure you have enabled "Install from Unknown Sources" in Settings → Security. If you're running Android 11 or higher, you may need to enable installation from your specific file manager app. Also ensure you have at least 3 GB of free storage space.

**❌ macOS Installation Fails**

If the installation still fails, make sure you have a stable internet connection and sufficient storage space available. The installation code must be obtained exclusively from the official website.
